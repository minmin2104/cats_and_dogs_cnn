# Cats And Dogs CNN

This repository contains a code to a demo of cats and dogs CNNs deep learning model
from my university assignment.

> [!IMPORTANT]
> This is just the code that test the accuracy of the predictor. I would want to add more
> stuff in this to be honest. Pretty soon. I promise.

## Build

It may take some time for the code to finish running.

```
git clone https://github.com/minmin2104/cats_and_dogs_cnn.git
cd cats_and_dogs_cnn
python -m venv .venv
pip install -r requirements.txt
python main.py
```
